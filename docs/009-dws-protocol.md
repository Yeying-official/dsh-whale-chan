# 009 DWS 协议

> 当前状态：占位（WS0）。尚未执行真实 `dws event` 订阅或发送；事件键、字段和信号语义待 WS1/WS2 实测后冻结。

## 本文件将覆盖

- 个人授权通道使用的事件键：消息、提及、会话/成员变化，以及可恢复游标。
- NDJSON 事件字段：事件 ID、会话键、发送者、消息类型、时间、原始载荷的保留与脱敏边界。
- 发送参数：目标类型/ID、正文、引用、显式请求 ID 与固定 AI 角标。
- SIGTERM 与订阅生命周期：启动、断线重连、优雅停止、强杀和游标恢复。
- 显式 ID 规则：入站事件、Thread、消息、Outbox 和发送确认的稳定标识。
- 待 WS2 实测项：Windows 信号行为、事件键稳定性、补收窗口、字段兼容性和真实发送确认。
