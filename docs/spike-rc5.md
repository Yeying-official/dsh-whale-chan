## 2. 与 superagent（0.2.1-alpha.2）的差异

1. **`WebServer.port` 变为可选**：rc.5 中 `get port(): number | undefined`，并新增 `getOrigin()`。superagent 的 `sameOrigin(req, ctx.webServer.port)` 写法在 rc.5 类型下需要先判断端口，或改用 origin。WS0 的管理路由没有复用那段检查。
2. **`WebRuntime` 构造配置变为必填**：alpha.2 的构造器配置可选，rc.5 是 `constructor(ctx: Context, config: WebRuntimeConfig)`，且 `searchProvider`/`fetchProvider` 为 `Volatile`。插件通过 DSH 组合注入，不手动构造，因此 WS0 无影响；WS2 若写测试必须传完整 config。
3. **`dsh-client-ui-slots` 不是客户端插件**：它没有 `dsh.client` 段，也没有 `./client` export，因此不能放进 `dsh.client.inject`。应只注入真正提供客户端服务的 `dsh-client-locale`、`dsh-client-ui-renderer`、`dsh-client-ui-layout`、`dsh-client-ui-sidebar`。superagent 的 inject 列表本来就没有 slots；WS0 已按此修正。
4. **Cordis / schemastery 稳定版**：`@deepseek-ai/cordis` 从 `4.0.5-alpha.1` 到 `4.0.5`、`schemastery` 从 `3.18.5-alpha.1` 到 `3.18.5`。本插件实际使用的 `Context`、`Service`、`s.effect`、`s.object`、`s.union` 没有签名变化；`s.union([s.const(...)])` 已在 `src/app/deployment.ts` 通过 typecheck。
5. **官方客户端 bundle 的工厂格式**：官方包与 superagent 都使用 `window.__ModuleLoader__.load({ id: "<package>", factory: (require) => { ... return module.exports; } })`；本仓库的 tsdown 输出已逐字覆盖此结构并验证 id。`dsh.client.inject` 只负责激活顺序，不把目标包当作 JavaScript `require` 目标。
6. **`useRemote` 在已安装的客户端包中没有找到对应导出**。这不是 rc.5 的公开 API；可用的同源方式是浏览器 `fetch`，Remote 服务则走生成式 `ctx.remote.<namespace>`（需要对应 controller 包）。WS0 不引入 Remote，只用相对 `fetch`。

## 3. 真机验证结论与仍未验证项

- **实际 Host 页面加载（已验证）**：2026-11-02 由审核方安装到 `desktop` profile，安装结果为 `application: applied`；宿主 Config 行 `status: schema`；客户端 bundle 经 `window.__ModuleLoader__` 真实加载；侧边栏出现「鲸鱼酱」，点击后主面板显示“已连接 / 0.1.0-dev.0 / 状态目录 / 启动时间”；`GET /whale-chan/api/state` 返回 200。该验证确认了 bundle id、slot 注册、locale 与面板 fetch 路径可用。同一轮审核后新增的 `x-whale-chan-request` 同源头由 `tests/state.spec.ts` 和 `tests/client-api.spec.ts` 覆盖。
- **`dws` 真机事件（仍未验证）**：WS0 明确不执行 `dws event` 订阅或发送。事件键、NDJSON 字段、SIGTERM 语义和真实消息格式留到 WS1/WS2 单独 spike，禁止根据 help 文本猜测键名。

## 4. 结论

WS0 用到的 rc.5 API 已从类型、运行中 Host 和一次真实 Web 安装三重核对，可以按当前写法实现。真实差异是 `WebServer.port` 变为可选；WS0 状态路由不依赖端口，故没有引入 `getOrigin()` 适配。客户端实际挂载已经闭环；唯一剩余的未知项是真实 dws 事件与发送。
